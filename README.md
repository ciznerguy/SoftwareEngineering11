# הנדסת תוכנה כיתה יא: פרויקט מלווה MixTape

כאן מנוהלים כל התכנים של שיעורי ההכנה בכיתה יא לקראת פרויקט הגמר של כיתה יב. לאורך השנה נבנה יחד פרויקט דוגמה אחד, **MixTape**, אתר לניהול שירים ופלייליסטים. כל יחידת לימוד מוסיפה לו שלב.

הפרויקט בנוי כפרויקט Blazor אחד. השכבות מופרדות לתיקיות בתוך אותו פרויקט: Models, Data, Controllers ו-Components.

כל יחידה מקבלת גרסה משלה, ולכל גרסה מצורף מדריך שמסביר מה נעשה בה.

| יחידה | נושא | קוד | מדריך |
|---|---|---|---|
| 1 | חזרה על Blazor: Razor, קלט, אירועים וניתוב | בקרוב | בקרוב |
| 2 | בסיס נתונים MySQL ושפת SQL: יצירת הטבלאות של MixTape, כולל טבלת המשתמשים, ושאילתות | בקרוב | בקרוב |
| 3 | מחלקה פשוטה ונתונים מהמסד: Song ב-Models, שליפה מ-MySQL ב-Data והצגה בדף | בקרוב | בקרוב |
| 4 | שירות API באותו פרויקט: GET, POST ו-CRUD | בקרוב | בקרוב |
| 5 | הרשמה וכניסה: דף הרשמה, דף כניסה וזכירת המשתמש המחובר | בקרוב | בקרוב |
