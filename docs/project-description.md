# תיאור הפרויקט MixTape

## הרעיון

האתר MixTape מאפשר לשמור שירים, לבנות מהם פלייליסטים ולראות אילו שירים הכי פופולריים בכיתה. כל תלמיד נרשם לאתר, נכנס עם שם משתמש וסיסמה, יוצר פלייליסטים משלו ומוסיף אליהם שירים מתוך מאגר משותף.

## מה אפשר לעשות באתר

- להירשם לאתר ולהיכנס עם שם משתמש וסיסמה
- לראות את רשימת כל השירים, ולחפש לפי שם או אמן
- להוסיף שיר חדש, לעדכן ולמחוק
- ליצור פלייליסט חדש עם שם ותיאור (רק משתמש מחובר)
- לראות את "הפלייליסטים שלי"
- להוסיף שירים לפלייליסט ולהוציא אותם ממנו
- לראות את השירים שמופיעים בהכי הרבה פלייליסטים

## הטבלאות

| טבלה | מה שומרים בה |
|---|---|
| `Users` | משתמשים: שם משתמש וסיסמה |
| `Songs` | שירים: שם השיר, אמן, ז'אנר, אורך בשניות |
| `Playlists` | פלייליסטים: שם, תיאור, המשתמש שיצר אותו (`UserId`), תאריך יצירה |
| `PlaylistSongs` | טבלה מקשרת: איזה שיר נמצא באיזה פלייליסט, ובאיזה מקום ברשימה |

לכל משתמש יכולים להיות הרבה פלייליסטים, וכל פלייליסט שייך למשתמש אחד.

שיר אחד יכול להופיע בהרבה פלייליסטים, ובפלייליסט אחד יש הרבה שירים. לכן צריך את הטבלה המקשרת `PlaylistSongs`.

בשלב זה הסיסמה נשמרת כטקסט רגיל, ואין באתר רמות הרשאה.

## מבנה הפרויקט

פרויקט Blazor אחד, והשכבות מסודרות בתיקיות:

```
MixTape/
  Models/        המחלקות: User, Song, Playlist
  Data/          המחלקות שמדברות עם בסיס הנתונים
  Controllers/   ה-API: הכתובות שמחזירות ומקבלות JSON
  Components/    דפי האתר
```

הדפים לא פונים לבסיס הנתונים ישירות. הם פונים ל-API, ה-API פונה למחלקות ב-Data, ורק Data מדבר עם MySQL.

## טכנולוגיות

- שפת C# בסביבת .NET 10
- ממשק משתמש ב-Blazor
- בסיס נתונים MySQL
- ניהול גרסאות ב-Git וב-GitHub
